## 희토류 연결

광석을 농축하고 공업용 약품으로 혼합 산화물을 얻은 뒤 분리기에서 다섯 종류의 산화물을 함께 생산한다. 단일 광석 조성이나 실제 분리 수율을 재현한 것은 아니다.

| 분리 산물 | 후속 용도 |
|---|---|
| 네오디뮴 산화물 | 네오디뮴 소재 → 영구자석 → 전기차·산업용 로봇 |
| 이트륨 산화물 | 기능성 세라믹 → 디스플레이 |
| 란타넘 산화물 | 광학 유리 → 디스플레이·항공 장비 |
