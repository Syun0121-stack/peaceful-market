# 0.1.3 → 0.2.0 저장 호환

기존 저장을 읽을 수 있도록 판매소, 크레딧, 금속 부품, 유리 제품, 전자 부품, 정밀 기계 부품과 기존 3개 공장의 내부 ID를 유지했습니다.
기존 점령 지역과 해금된 연구는 취소하지 않습니다. 기존 지역 누적 매출은 새 목표의 매출 실적으로 한 번 이관합니다.

기존 공장은 다음과 같이 바뀝니다.

| 이전 | 새 이름 |
|---|---|
| 금속 부품 공장 | 기초 금속 가공소 |
| 유리 제품 공장 | 유리·세라믹 공장 |
| 다품목 조립 공장 | 다품목 기계 공장 |

생산법이 변경되어 기존 공장의 **선택 생산품과 진행률만 초기화**합니다. 저장된 원료·완제품은 보존합니다.
업데이트 후 공장별 생산품과 컨베이어 투입 재료를 다시 설정하십시오. 필요 없어진 잔여 재료는 언로더로 회수할 수 있습니다.
이전 공장을 철거하고 다시 건설할 필요는 없습니다. 0.1.1에서 아예 저장되지 않았던 판매소는 예외입니다.

기존 코어의 크레딧은 기업 본부의 **코어 크레딧 전액 입금**으로 새 계좌에 넣습니다. 새 회사 주가는 100, 해임 유예 시간은 처음부터 시작합니다.
신규 광맥은 기존 구조물이나 기존 광맥을 덮어쓰지 않고 빈 육지에 추가됩니다. 이미 점령한 지역은 새 생산 목표를 다시 채울 필요가 없습니다.

업데이트 후 전투 유닛이 제거되고 전투 전용 생산시설은 비활성화됩니다. 코어 조작 유닛과 모노·폴리·메가는 유지합니다.
되돌리려면 업데이트 전에 게임의 **전체 데이터 내보내기**로 백업하십시오. 새 아이템이 든 저장은 구버전에서 정상적으로 읽힌다고 보장하지 않습니다.

기업 계좌·주식·주가는 게임 설정에 캠페인 전체 상태로 저장하고, 지역별 매출·생산·판매 실적은 해당 지역 저장에 저장합니다.
따라서 다른 기기로 옮길 때는 개별 지역 저장만 복사하지 말고 **전체 게임 데이터**를 옮기십시오. 이전 지역 저장만 되돌리면 기업 계좌도 함께 되돌아가는 구조는 아닙니다.

주요 경제 진행은 문서에 나열된 12개 지역에 적용합니다. 나머지 세르플로 지역에는 구리 전선 생산·판매와 매출의 공통 목표가 표시됩니다.
에르키르 경제 캠페인과 멀티플레이는 지원하지 않습니다. 전투 유닛 생산 목록 변경 자체는 전역 콘텐츠 변경입니다.
