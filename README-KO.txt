고요한 시장 0.1.1 — Mindustry 160.7 대상 싱글플레이 초안

설치: Mindustry → 모드 → 모드 가져오기 → 이 ZIP 선택 → 재시작.
압축을 풀어서 다른 ZIP 안에 넣지 마세요. 루트에 mod.json이 있는 ZIP입니다.

사용:
1. 세르플로 캠페인에 들어갑니다. 새 게임/별도 백업 저장에서 사용하는 것을 권장합니다.
2. 효과(Effect) 건설 탭에서 판매소를 짓습니다. 구리 35, 납 20 필요.
3. 컨베이어로 판매소에 자원을 넣습니다. 반입 즉시 판매하고 크레딧은 코어에 저장합니다.
4. 판매소를 누르고 시세표를 선택합니다. 실제 플레이 시간 3분마다 기준가의 약 65~135%로 변합니다. 일시정지 동안 시계도 멈춥니다. 품목별 가격은 서로 다릅니다.
5. 연구 트리의 지정 지역을 크레딧으로 연구하고 행성 화면에서 출발합니다. 원래의 선행 연구 트리와 발사 자원 조건은 적용됩니다.

크레딧 비용 변경 지역(순서대로): 얼어붙은 숲, 생체 자원 생산 단지, 폐허의 해안, 얼룩진 산맥, 바람 부는 섬, 타르 벌판, 과성장 지대, 충격 지대 0078, 황폐한 협곡, 행성간 발사 터미널.
가격: 150부터 175씩 증가. 나머지 이름 있는 지역은 기존 연구 방식입니다.
번호만 있는 지역으로 자유 발사하는 경로는 막아 둡니다.
기존에 이미 해금한 지역은 다시 잠그지 않습니다.
새 행성이나 신규 맵이 아니라 기존 세르플로 캠페인을 경제 중심으로 바꾸는 모드입니다.

평화 모드: 세르플로 지역 로드시 적 부대와 적 건물을 제거하고 웨이브와 침공을 끕니다.
기존 저장에서 로드 후 저장하면 적 건물 제거도 저장됩니다. 원래 전투 진행으로 되돌리려면 설치 전 저장을 백업하세요.
코어의 크레딧 저장 공간이 부족하면 판매소 반입이 멈춥니다. 코어/창고 확장 또는 지역 연구로 해결하세요.
원래 산업·연구는 자원을 사용하며 판매에 투입한 물품은 반환되지 않습니다.

검증 범위: Mindustry 160.7 서버 엔진에서 모드 로딩, 캠페인 로딩, 적 제거, 웨이브 비활성화, 판매소 반입 및 코어 크레딧 증가 확인. Android 화면과 시세표 UI는 미검증.
Android/PC 공통 JS 모드 형식이나 다른 버전 및 다른 모드와의 호환성은 미검증입니다.
멀티플레이에는 사용하지 마세요.
