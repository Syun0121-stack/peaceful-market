처음 시작할 때: 구리·납 → 판매소 → 기초 금속 가공소 연구 → 구리 전선 생산·판매.
첫 지역 목표: 매출 600크레딧 + 구리 전선 40개 현지 생산 및 판매.
다음 지역은 판매소 또는 기업 본부의 '지역 개방'에서 구매하고 행성 화면에서 출발합니다.

완제품 28종, 전체 아이템 82종, 공장 17종, 생산법 66개.
휴대폰·태블릿·노트북·TV, 가전 6종, 차량·열차·중장비, 민수 항공기·함선,
일회용품·포장재·산업용 로봇·AI 데이터센터 설비와 추상적인 방산 전시 상품을 판매합니다.
제품은 아이템이며 전투 유닛으로 사용하지 않습니다. 코어 유닛·모노·폴리·메가는 유지합니다.

자원은 지역별 광맥으로 추가됩니다. 공장 클릭 → 생산품 선택 → 원료 투입 → 컨베이어로 판매소 연결.
희토류 분리기는 네오디뮴·이트륨·란타넘·세륨·디스프로슘 산화물을 함께 생산합니다.
부산물도 모두 배출하십시오. 한 품목이라도 저장 공간이 부족하면 분리가 중단됩니다.

수익은 기업 계좌에 저장되어 코어 용량 제한을 받지 않습니다.
기존 코어 크레딧은 기업 본부에서 입금합니다. 연구용 인출도 가능합니다.
지역별 생산 실적은 수입품 구매만으로 채울 수 없습니다.

시세: 3분마다 직전 가격의 ±10%, 기준가의 60~150%.
수입: 현재 시세 ×1.35 +3크레딧. 원료·중간재·일부 완제품 지원.
투자: 단계 2부터 4개 회사의 주식 거래·배당. 과반 지분과 추가 대금으로 인수.
인수: 업종 생산속도 +15%, 가공료 -15%. 원료 수량은 동일.
자사 주가: 첫 완제품 판매 후 활동 시간 30분 유예. 20 미만 결산 3회 연속이면 CEO 해임.
일시정지·게임 종료 중에는 회사 시간이 흐르지 않습니다.

기존 공장 원료는 유지되지만 선택 생산품과 진행률은 새 생산법에 맞춰 초기화됩니다.
기존 점령·연구는 유지됩니다. 전체 데이터 백업 후 업데이트하십시오.
공정은 현실의 큰 단계를 참고한 게임 모델이며 실제 배합비·제조 조건·전체 공정을 재현하지 않습니다.
Android UI·터치와 전체 캠페인 장시간 밸런스는 아직 검증하지 못했습니다.
